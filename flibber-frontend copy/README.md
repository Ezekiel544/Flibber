# FLIBBER Frontend

## Setup
```bash
npm install
npm run dev
```

Open http://localhost:3000

## Pages
- `/`           → Slot assets (main feature)
- `/pool`       → Liquidity pool (deposit/withdraw/claim)
- `/stake`      → Stake $FIB for yield
- `/governance` → Vote on proposals
- `/dashboard`  → Protocol stats + your positions

## Requirements
- MetaMask installed
- Connected to Base Sepolia (Chain ID: 84532)
- Testnet ETH for gas
- Test tokens from faucet
